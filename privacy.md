# EasyLogger Privacy Policy

**Effective Date:** August 5, 2026

EasyLogger is a .NET logging library for Windows Forms, Console Applications, and WPF.

## 1. Scope
As a software library, EasyLogger provides developers with tools to record application events.

## 2. Data Handling
EasyLogger writes log data to the destinations (such as local files or console output) configured by the developer using the library. It does not automatically transmit any logged data to external servers or third parties.

## 3. Developer Responsibility
Developers using EasyLogger are responsible for ensuring that the data they choose to log complies with their own privacy policies and relevant regulations.
